# ReactJS HOL 3 - Score Calculator App

## Objective

Create a React application using a functional component to calculate and display a student's average score.

## Technologies Used

- React
- JavaScript
- CSS
- Node.js
- npm

## Project Name

scorecalculatorapp

## Components

- CalculateScore (Functional Component)

## Features

- Displays Student Name
- Displays School Name
- Displays Total Marks
- Displays Number of Subjects
- Calculates and displays Average Score
- Uses external CSS styling

## Run the Application

```bash
npm install
npm start
```

Application URL:

```
http://localhost:3000
```

## Production Build

```bash
npm run build
```
