# ReactJS HOL 4 - Blog Application

## Objective

Implement React component lifecycle methods by fetching blog posts from an external REST API.

## Technologies Used

- React
- JavaScript
- Fetch API
- Node.js
- npm

## Project Name

blogapp

## Concepts Covered

- Class Components
- Constructor
- State
- componentDidMount()
- componentDidCatch()
- Fetch API
- Rendering Lists

## API Used

https://jsonplaceholder.typicode.com/posts

## Features

- Fetches posts from REST API
- Displays blog title and body
- Uses React lifecycle methods
- Handles errors

## Run

```bash
npm install
npm start
```

Application URL

```
http://localhost:3000
```

## Production Build

```bash
npm run build
```
