# ReactJS HOL 1 - My First React Application

## Objective

Create a simple React application that displays a welcome message.

## Technology Stack

- React
- JavaScript
- HTML
- CSS
- Node.js
- npm

## Project Name

myfirstreact

## Output

```
Welcome to the first session of React
```

## Run the Project

```bash
npm install
npm start
```

The application runs at:

```
http://localhost:3000
```

## Build

```bash
npm run build
```

## Status

Completed successfully.
