### Agile Methodology

- What is Agile
- Benefits of Agile
- Agile Principles

### Agile vs Waterfall

| Agile | Waterfall |
|--------|-----------|
| Iterative | Sequential |
| Continuous Feedback | Fixed Requirements |
| Flexible | Less Flexible |
| Faster Delivery | Longer Delivery Cycle |

### Scrum Framework

Roles

- Product Owner
- Scrum Master
- Development Team

Ceremonies

- Sprint Planning
- Daily Scrum
- Sprint Review
- Sprint Retrospective

Artifacts

- Product Backlog
- Sprint Backlog
- Increment

### User Stories

Format:

As a <user>

I want <feature>

So that <benefit>

Example:

As a customer

I want to reset my password

So that I can access my account.

### Story Points

Used for effort estimation.

Common Fibonacci Scale:

- 1
- 2
- 3
- 5
- 8
- 13
- 21

### Burndown Chart

Used to measure sprint progress.

### Definition of Done

A feature is considered complete only after:

- Code completed
- Code reviewed
- Tested
- Documentation updated
- Ready for deployment
