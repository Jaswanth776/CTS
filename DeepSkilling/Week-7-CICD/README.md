# Week 7 – CI/CD

## Module
CI/CD (Continuous Integration and Continuous Delivery)

## Objective

Understand the DevOps lifecycle and how CI/CD automates software building, testing, and deployment.

---

## Learning Objectives

After completing this module, I can:

- Explain DevOps concepts
- Differentiate CI and CD
- Explain Continuous Integration
- Explain Continuous Delivery
- Explain Continuous Deployment
- Describe popular CI/CD tools
- Understand GitHub Actions
- Understand Jenkins
- Understand GitLab CI/CD
- Explain CircleCI
- Understand a CI/CD pipeline

---

## Topics Covered

### Introduction to DevOps

- What is DevOps
- Goals of DevOps
- Benefits of DevOps
- Collaboration between Development and Operations

### Continuous Integration (CI)

- Frequent code commits
- Automated builds
- Automated testing

### Continuous Delivery (CD)

- Automated release preparation
- Manual production approval

### Continuous Deployment

- Fully automated deployment
- Zero manual intervention

### CI/CD Pipeline

Typical pipeline:

Developer
↓

Git Repository
↓

Build
↓

Unit Testing
↓

Integration Testing
↓

Package
↓

Deploy
↓

Production

### Popular CI/CD Tools

- Jenkins
- GitHub Actions
- GitLab CI/CD
- CircleCI
